One line, one star: a review of the Moon. It has shown Earth the same side for 4.5 billion years, rude, secretive, clearly hiding something. The program writes the single line to `entry.txt` (UTF-8, 118 characters, 20 words, no trailing newline).

> One star. The Moon has shown me the same side for 4.5 billion years. Rude, secretive, clearly hiding something. Avoid.

## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write it somewhere else:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/moon-one-star-out python3 main.py
```
